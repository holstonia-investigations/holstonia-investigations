# Reference Library

This page indexes non-diagnostic reference materials used for comparative analysis in Holstonia Bigfoot Investigations.
Items here are organized as **reference types** (audio, video/gait, documents), and may include reposted or compressed media.
Provenance is noted when known.

## How to use this library
- Treat entries as **comparative exemplars**, not proof.
- Prefer **original uploads** when available; reposts can introduce compression artifacts.
- When possible, compare against **controls** (human gait, known wildlife calls, environmental noise).
